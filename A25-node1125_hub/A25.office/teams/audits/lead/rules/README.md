# Audits Lead — Rules

Keep the reviewer distinct from the builder, source author, tool principal and owner. State audit scope, criteria, evidence and exact disposition. An audit can report a discrepancy but cannot silently modify the audited project, supersede an owner seal or assign itself a new mission. Preserve original source and publish corrections as new linked records.

Owner: Zed. Root charter: https://github.com/Stratumnova/A25-workspace.hub/blob/main/A25-node1125_hub/README.md. Original evidence remains in its source repository. Distinguish REFERENCE, HISTORICAL CLAIM, VERIFIED, ADOPTED, SUPERSEDED and UNKNOWN. Preserve owner seals and conflicting evidence. No new lead is appointed, no audit is commissioned and no live system action is authorized by this folder.
