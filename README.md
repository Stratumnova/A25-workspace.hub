## One-project-one-home rule

A new substantive project begins under `A25-node1125_hub/A25.archives/projects/`. The same folder is used while active, paused, completed or abandoned. Do not create a separate active-session tree, second project archive or migration step. Project 11's internal `archives/` is reserved for its own experimental history; link any related canonical A25 project rather than silently creating duplicate sources of truth.

## Common operating rules

Read the charter and the relevant landing README first. Follow the owner's current scope and authority. Preserve original records, exact author identities, evidence provenance, unresolved GPT/Claude disagreements and owner seals. New dated records require actual UTC time and the charter's metadata. Do not invent tests, approvals or status. Keep private material and secrets out of public GitHub. Do not create branches, repositories, live services or deployment changes without authorization.

If a needed subfolder is missing, **use the existing project folder and its README or a relevant existing team area first**; only add structure for real work, not empty paperwork. Office routes work, Archives holds the project history, and Chat holds free conversation. These functions must remain linked but not duplicated.
